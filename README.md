# 📊 Data Professional Survey Breakdown

An interactive **Power BI Dashboard** analyzing survey responses from over **630 data professionals** to uncover key trends in compensation, tool preferences, and job satisfaction.

#  Key Insights

 *Compensation:** Data Scientists, Data Engineers, and Data Architects report the highest average salaries.
*Favorite Programming Language:** Python is the most popular language among data professionals, followed by R.
*Satisfaction Scores:**
*Work-Life Balance:** 5.74 / 10
*Salary Satisfaction:** 4.27 / 10
*Demographics:** Covers top regions including the US, UK, India, and Canada (Average Age: 29.87).



# Tech Stack & Methods

* **Tool:** Microsoft Power BI Desktop
* **Data Prep:** Power Query (Data cleaning, unnesting survey responses, type casting)
* **Analytics:** DAX Measures for averages, satisfaction gauges, and response counts
